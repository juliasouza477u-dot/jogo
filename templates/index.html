✝️ Jogo Catecismo

Atire nas pedras com números, responda perguntas de catecismo e não deixe nada te atingir!

Como jogar

  • Arraste o dedo para mover o atirador para os lados.
  • Toque no botão ATIRAR para disparar para cima.
  • Pedras com número > 1 se dividem quando são atingidas.
  • De tempos em tempos aparece uma pergunta de catecismo (pausa o jogo).
  • Acertar = +25 pontos · Errar = −10 pontos.
  • Se uma pedra tocar em você, você perde uma vida. Sem vidas = game over.
